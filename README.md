## What Is Delta Exec?

Delta Exec is a Windows desktop executor for Roblox Lua. It pairs a small UI with injection, a packaged script hub, and tools meant for people who load scripts often rather than once in a while.

Instead of packing the window with unused chrome, the product leans on workflow pieces: automatic updates, multi-script runs, queues that survive restarts on disk, and an integrated debugger. Target environment is Windows 10/11 on 64-bit machines.

## Key Features

- Single-click injection so scripts reach an active Roblox session with less setup friction
- Onboard hub carrying 500+ scripts, organized so you can search by category
- Auto-update path that refreshes the installed desktop build when new versions ship
- Local queue persistence so batched scripts remain saved on your PC
- Batch runners that fire several Lua items inside one session
- UI language choices for broader desktop usability
- Debugger panel for watching how scripts behave while you test
- Install size kept under 40 MB to limit disk and resource use

## FAQ

**Is Delta Exec tied to Windows only?**  
Yes. Shipping builds target Windows 10/11 on 64-bit hardware only.

**Will script support stay current after updates?**  
Auto-update is part of the product so clients can track newer releases without a full manual reinstall each time.

**How is this different from other Roblox executors?**  
The design stress is low footprint, an included hub, batch runs, and on-device queue storage instead of a bulky shell.

**Can using a script executor affect my account?**  
Third-party executors can conflict with Roblox rules; account outcomes are your responsibility under their terms.

**Does Delta Exec store anything locally?**  
It does. Saved script batches live in persistent local queue storage on the machine.
